# Network Protocol Classification Using Machine Learning

## Project Overview

This project uses Machine Learning algorithms to classify network protocols based on packet information.

## Objective

To predict network protocols using packet features and compare the performance of different Machine Learning models.

## Dataset

KT_GameBox_1.csv

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Machine Learning Algorithms

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Decision Tree
* Random Forest

## Project Workflow

1. Dataset loading
2. Data exploration
3. Data cleaning
4. Feature engineering
5. Data visualization
6. Model training
7. Model evaluation
8. Model comparison
9. Protocol prediction

## Results

The models were evaluated using accuracy, classification reports, and confusion matrices.

## How to Run

1. Download the project notebook.
2. Open it using Google Colab or Jupyter Notebook.
3. Upload the required dataset.
4. Run the notebook cells in order.
